1트 코드
```java
import java.util.*;

class Solution {
    public int solution(int[] nums) {
        int answer = 0;
        
        HashSet <Integer> type = new HashSet<>();
        
        for(int i = 0; i < nums.length; i++)
            type.add(nums[i]);
        if(type.size() >= nums.length / 2)
            answer = nums.length / 2;
        else
            answer = type.size();

        
        return answer;
    }
}
```
### 핀포인트
hashset에서 add를 하면 그 종류(중복)만 value가 저장되는 형식.
그래서 type에는 종류만 들어있고 size로 종류 수. 
answer을 결정. 같거나 많으면 선택할수 있는 nCr에서 r이 답.
는 거고 작으면 어차피 작은 게 곧 답.
